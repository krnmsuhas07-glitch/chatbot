# 🤖 AI Chatbot

A simple AI chatbot built to practice **HTML, CSS, JavaScript, and API integration**.

## 🚀 Live Project

This project demonstrates how a frontend application can communicate with an AI API and display responses dynamically.

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Groq API

## ✨ Features

* Chat-style user interface
* AI-powered responses
* Dynamic message rendering
* API integration using JavaScript
* Responsive and simple UI

## 📚 What I Learned

* DOM manipulation
* JavaScript event handling
* `fetch()` and API requests
* Working with JSON responses
* Async/await
* Frontend UI development
* Integrating third-party APIs
* Using Git and GitHub

## 🔐 API Key Disclaimer

For demonstration purposes, this project uses a client-side API integration to showcase the complete functionality of the application.

**The API key included in this repository is intentionally exposed for this learning project.** This is a conscious trade-off made to demonstrate the application's functionality and my understanding of frontend API integration.

This implementation is **not intended for production use**. In a production application, API credentials should be kept private and handled through a secure backend or server-side environment variable.

## 🎯 Purpose

This project is part of my web development learning journey, with a focus on building practical projects and understanding how frontend applications interact with external APIs.
